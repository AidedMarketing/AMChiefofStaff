# relationships.md — Who's who

One entry per person or org that matters. The triage skill reads this to decide
tier, priority, and register. Unknown senders get a stub appended automatically
at the end of each run for Adrian to fill in or delete.

## Format

```
### Name <email@domain>
- **Relationship:** client | prospect | vendor | partner | press | personal
- **Register:** formal | neutral | warm
- **Context:** what we're doing together, one or two lines
- **Priority floor:** P1 | P2 | P3 — never rank below this
- **Notes:** anything that changes how to reply (prefers phone, timezone, etc.)
- **Last touch:** YYYY-MM-DD — maintained by the agent
```

## Priority floor guidance

- **P1** — active paying client, or anything with a deadline inside 48h
- **P2** — prospect in conversation, partner, anything with a deadline this week
- **P3** — everything else that still deserves a human reply
